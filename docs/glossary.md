# ACE Framework Glossary

Domain terminology for the ACE (AI Competency Evaluation) framework. All review
feedback should use these terms consistently.

## Core Types

| Term | Definition |
|------|-----------|
| Zone | A level of AI adoption maturity (0-4), representing a destination, not a ranking |
| Zone 0 (Baseline) | Traditional software development with no meaningful AI integration |
| Zone 1 (Augmenting) | Individual team members use AI tools habitually in daily work |
| Zone 2 (Integrating) | AI is embedded in team-level delivery workflows |
| Zone 3 (Accelerating) | AI drives core development work; humans specify, review, orchestrate |
| Zone 4 (Industrializing) | AI-first software factory; engineers maintain the factory |
| Competency | Habitual behavior under stress, not knowledge or peak-day performance |
| Proficiency | A specific observable behavior within a zone |
| Diagnostic | A facilitated self-assessment workshop that produces a zone-level score |
| Facilitator | An Artium-certified professional who delivers ACE diagnostics |
| Organizational Investment | Structural, policy, resource, or cultural changes required for a zone |

## Competency Stages

| Term | Definition |
|------|-----------|
| Emerging | Initial exposure; behavior is inconsistent and requires prompting |
| Developing | Behavior is practiced but not yet habitual; reverts under stress |
| Established | Behavior is habitual under moderate pressure; practical sustainability threshold |
| Consistent | Meets all three quantitative threshold criteria (composite >= 4.7, SD <= 0.5, no question below 4.0); a positive, legitimate classification |
| Exemplary | Consistent plus coaching capability, contextual adaptation, and practice innovation; requires facilitator qualitative assessment |

## Engagement Phases

| Term | Definition |
|------|-----------|
| Discovery | Initial engagement phase to understand organizational context |
| Diagnostic | Facilitated self-assessment workshop producing zone scores |
| Goal Setting | Leadership session to select target zone based on strategic fit |
| Collaborative Delivery | Embedded Artisans work alongside client teams to build capability |

## Assessment Terms

| Term | Definition |
|------|-----------|
| Composite Score | Average of all proficiency ratings for a zone |
| Threshold | Minimum composite score to establish a zone (>= 4.7) |
| Standard Deviation | Measure of score consistency (target: <= 0.5) |
| Dual Reporting | Separate team reports (detailed) and management reports (aggregate) |

## Type Design Principles

- Zone numbers are progression indicators, not quality rankings
- Higher zones are not inherently "better" — strategic fit determines the right zone
- Competency is measured by behavior, not knowledge or aspiration
- Cross-craft inclusivity: all terms apply to engineering, PM, design, and QA roles
