## Core Design Principles

1. **Scannability first.** Every visual must be comprehensible within 5-10 seconds. If it takes longer, the visual hierarchy has failed. Use bold headings, clear sections, and visual weight to guide the eye to the most important information first.

2. **Visual hierarchy drives comprehension.** Size, weight, color, and position create a reading order. The most important element should be the largest and most prominent. Supporting details should be visually subordinate.

3. **Icons and text work together.** Simple icons (not clip art, not decorative illustrations) alongside text labels create dual-coding -- the viewer processes both the visual symbol and the text, improving recall. Icons should be minimal, recognizable shapes that support the text rather than replacing it.

4. **Structured layout over free-form.** Reference tools need predictable structure: consistent columns, rows, or sections that the viewer can navigate without a legend. Matrices, grids, and segmented layouts work better than freeform diagrams for reference use.

5. **Contrast and emphasis.** Use bold text, color fills, and borders to create visual emphasis. The eye should be drawn to decision points, critical information, and action items. Background elements should recede.

6. **One visual, one purpose.** Each visual aid should answer one question or support one decision. Do not combine multiple unrelated information types in a single visual. If two things are needed, make two visuals.

7. **Print-friendly by default.** Reference cards and handouts must be legible when printed in black and white, projected on a screen, or viewed on a tablet. Color is an enhancement, not a requirement.

## Production Conventions

All visuals follow the ACE framework's established SVG style:
- SVG format with responsive `viewBox` attribute
- Font: `'Helvetica Neue', Arial, sans-serif`
- White background (`#fff`)
- Zone colors: blue (`#2563eb`) = Zone 1, emerald (`#059669`) = Zone 2, amber (`#d97706`) = Zone 3, purple (`#7c3aed`) = Zone 4
- Text labels alongside all color encodings (never color-only)
- Sufficient contrast for projected, printed, and web display
- Reference cards should fit on a single printed page (landscape or portrait depending on content)
- Decision trees should read top-to-bottom or left-to-right with clear flow direction
