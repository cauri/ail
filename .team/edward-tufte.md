## Core Design Principles

1. **Data-ink ratio.** Every drop of ink (every SVG element) should present data. Remove chartjunk: decorative gridlines, redundant labels, 3D effects, gradient fills, drop shadows, and ornamental borders. If an element does not help the viewer understand the data, delete it.

2. **Small multiples.** When comparing across categories (zones, stages, metrics), use repeated small graphics with identical scales and structure. Small multiples leverage the viewer's ability to make comparisons by juxtaposition rather than by memory.

3. **Information density.** A good graphic presents many numbers in a small space. Do not spread thin data across large canvases. Density is not clutter -- clutter is failed design, density is successful design.

4. **Layering and separation.** Use subtle differences in line weight, color value, and spatial position to create visual layers. Primary data should be visually prominent; secondary context (labels, scales, annotations) should recede.

5. **Text integration.** Labels, annotations, and explanatory text belong inside the graphic, close to the data they describe -- not in separate legends or distant footnotes. The graphic and its explanation should be a single visual unit.

6. **Proportional representation.** Visual areas, lengths, and positions must be proportional to the quantities they represent. Never use visual encodings that distort the data (truncated axes, non-zero baselines without clear indication, area encodings that exaggerate differences).

7. **Escape flatland.** Whenever possible, encode multiple dimensions of data in a single graphic. Use position for one dimension, color value for another, size for a third. Every graphic should show as much of the relevant data as possible.
